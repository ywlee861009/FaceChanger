# 사용자 플로우

## 전체 플로우 개요

```
앱 실행
  └→ 스플래시 (1.5초)
       └→ 홈 화면
            ├→ [실시간 변경]
            │    └→ 카메라 권한 확인
            │         ├→ 거부: 권한 안내 화면
            │         └→ 허용: 실시간 카메라 화면
            │                   └→ 얼굴 인식 (사람 + 강아지)
            │                        └→ 실시간 얼굴 교환 적용
            │                             └→ [촬영] → 결과 화면
            │                                          ├→ 저장
            │                                          ├→ 공유
            │                                          └→ 다시 찍기 → 실시간 카메라 화면
            └→ [사진 변경]
                 └→ 미디어 권한 확인
                      ├→ 거부: 권한 안내 화면
                      └→ 허용: 사진 선택 화면
                                └→ 강아지 사진 선택 + 사람 사진 선택
                                     └→ 얼굴 인식 및 처리
                                          ├→ 실패: 안내 메시지 + 재선택
                                          └→ 성공: 결과 화면
                                                    ├→ 저장
                                                    ├→ 공유
                                                    └→ 다시 하기 → 사진 선택 화면
```

---

## 1. 스플래시 화면

- 앱 실행 시 1.5초간 표시
- 앱 로고 및 브랜드 표시
- 1.5초 후 자동으로 홈 화면으로 전환

---

## 2. 홈 화면

- **[실시간 변경]** 버튼: 전면 카메라로 실시간 얼굴 교환
- **[사진 변경]** 버튼: 갤러리에서 사진을 선택해 얼굴 교환

---

## 3. 실시간 변경 플로우

### 3-1. 권한 처리
- `CAMERA` 권한 확인
  - 미허용 → 카메라 권한 안내 화면 (설정으로 이동 버튼 포함)
  - 허용 → 실시간 카메라 화면으로 진입

### 3-2. 실시간 카메라 화면
- 전면 카메라 프리뷰 활성화
- 사람 얼굴 + 강아지 얼굴을 동시에 인식
  - 사람 얼굴만 인식됨: "강아지도 같이 비춰주세요!" 안내
  - 강아지만 인식됨: "사람 얼굴도 필요해요!" 안내
  - 둘 다 인식됨: 실시간으로 얼굴 교환 적용, 촬영 버튼 활성화
- **[촬영]** 버튼 탭 → 현재 프레임 캡처

### 3-3. 결과 화면
- 교환된 결과 이미지 표시
- **[저장]**: 갤러리에 저장
- **[공유]**: Android 공유 시트 (카카오톡, 인스타그램 등)
- **[다시 찍기]**: 실시간 카메라 화면으로 복귀

---

## 4. 사진 변경 플로우

### 4-1. 권한 처리
- `READ_MEDIA_IMAGES` 권한 확인
  - 미허용 → 미디어 권한 안내 화면 (설정으로 이동 버튼 포함)
  - 허용 → 사진 선택 화면으로 진입

### 4-2. 사진 선택 화면
- **강아지 사진 선택**: 갤러리에서 강아지 사진 선택
- **사람 사진 선택**: 갤러리에서 사람 사진 선택
- 두 사진이 모두 선택되면 **[교환하기]** 버튼 활성화

### 4-3. 처리 화면
- 각 사진에서 얼굴 인식 및 교환 처리 중 로딩 표시
  - 얼굴 인식 실패: "얼굴을 찾지 못했어요" 안내 + 재선택 유도
  - 처리 성공 → 결과 화면으로 전환

### 4-4. 결과 화면
- 교환된 결과 이미지 표시
- **[저장]**: 갤러리에 저장
- **[공유]**: Android 공유 시트
- **[다시 하기]**: 사진 선택 화면으로 복귀

---

## 5. 에러 처리

| 상황 | 대응 |
|------|------|
| 카메라 권한 없음 | 안내 화면 + 설정 이동 버튼 |
| 미디어 권한 없음 | 안내 화면 + 설정 이동 버튼 |
| 얼굴 인식 실패 | "얼굴을 찾지 못했어요" + 재시도 안내 |
| 처리 중 오류 | "앗, 문제가 생겼어요!" + 다시 시도 버튼 |
| 저장 공간 부족 | "공간이 부족해요" + 정리 안내 |

---

## 6. 권한 요구사항

| 권한 | 용도 | 필수 여부 |
|------|------|-----------|
| `CAMERA` | 실시간 카메라 프리뷰 및 촬영 | 실시간 변경 필수 |
| `READ_MEDIA_IMAGES` | 갤러리에서 사진 선택 | 사진 변경 필수 |
| `WRITE_EXTERNAL_STORAGE` | 결과 이미지 저장 (API 28 이하) | 선택 |
