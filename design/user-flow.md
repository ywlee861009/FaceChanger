# 사용자 플로우

## 메인 플로우: 카메라로 얼굴 교환

```
스플래시 → 메인 카메라 → [촬영] → 처리 화면 → 결과 화면
                                                  ├→ 저장
                                                  ├→ 공유
                                                  └→ 다시 찍기 → 메인 카메라
```

### 상세 단계

1. **앱 실행** → 스플래시 화면 (1.5초)
2. **카메라 권한 확인**
   - 첫 실행 시: 귀여운 강아지 일러스트와 함께 권한 요청 안내
   - 권한 거부 시: 설정으로 이동 안내 화면
3. **카메라 프리뷰 활성화**
4. **얼굴 인식 대기**
   - 사람 얼굴만 인식: "강아지도 같이 비춰주세요!" 안내
   - 강아지만 인식: "사람 얼굴도 필요해요!" 안내
   - 둘 다 인식: 촬영 버튼 활성화 + 얼굴 주위에 테두리 표시
5. **촬영 버튼 탭** → 셔터 애니메이션 + 이미지 캡처
6. **얼굴 교환 처리** (로딩 화면, 2~5초)
7. **결과 표시** → 비교 슬라이더로 원본/결과 비교 가능

## 서브 플로우: 갤러리에서 사진 선택

```
메인 카메라 → [갤러리 버튼] → 기기 갤러리 → 사진 선택 → 처리 화면 → 결과 화면
```

### 상세 단계

1. **갤러리 버튼 탭** → Android 기본 사진 선택기 열림
2. **사진 선택** → 선택한 사진에서 얼굴 인식 시도
   - 사람 + 강아지 얼굴 모두 있음: 처리 진행
   - 얼굴 부족: "사람과 강아지가 함께 있는 사진을 골라주세요!" 안내
3. **결과 화면** (메인 플로우와 동일)

## 서브 플로우: 결과 저장 및 공유

```
결과 화면 → [저장] → 갤러리에 저장 완료 토스트
결과 화면 → [공유] → Android 공유 시트 (카카오톡, 인스타 등)
```

## 서브 플로우: 내 컬렉션 확인

```
메인 카메라 → [최근 결과 썸네일 탭] → 갤러리 화면 → [항목 탭] → 결과 화면
```

## 에러 처리

| 상황 | 대응 |
|------|------|
| 카메라 권한 없음 | 귀여운 안내 화면 + 설정 이동 버튼 |
| 얼굴 인식 실패 | "얼굴을 찾지 못했어요" + 재시도 안내 |
| 처리 중 오류 | "앗, 문제가 생겼어요!" + 다시 시도 버튼 |
| 저장 공간 부족 | "공간이 부족해요" + 정리 안내 |
| 네트워크 오류 (필요 시) | "인터넷 연결을 확인해주세요" |

## 권한 요구사항

| 권한 | 용도 | 필수 여부 |
|------|------|-----------|
| `CAMERA` | 실시간 카메라 프리뷰 및 촬영 | 필수 |
| `READ_MEDIA_IMAGES` | 갤러리에서 사진 선택 | 선택 |
| `WRITE_EXTERNAL_STORAGE` | 결과 이미지 저장 (API 28 이하) | 선택 |
