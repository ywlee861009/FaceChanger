# 06. 설정 화면

## 앱 개요
FaceChanger — 강아지와 사람의 얼굴을 바꿔주는 카메라 앱. 아기자기하고 귀여운 감성.

## 스타일 요약
- **Primary:** Peach Pink `#FF8FAB`, Soft Coral `#FFB3C1`, Warm Cream `#FFF5E4`
- **Secondary:** Sky Lavender `#C8B6FF`, Mint Green `#B8F3CE`, Puppy Brown `#8B6F47`
- **텍스트:** Dark Cocoa `#3D2C2E`, 보조 Warm Gray `#9E8E8E`
- **배경:** Light Cream `#FFFAF3`, Pure White `#FFFFFF`
- **폰트:** Pretendard / 제목 24sp Bold, 소제목 18sp SemiBold, 본문 14sp Regular, 캡션 12sp
- **모서리:** 버튼 24dp, 카드 16dp
- **톤앤매너:** 파스텔톤, 둥근 형태, 부드러운 그림자

## 화면 구성

### 상단 바
- 배경: Light Cream
- **좌측:** 뒤로가기 화살표 (Dark Cocoa)
- **중앙:** "설정" (18sp SemiBold, Dark Cocoa)

### 설정 항목 리스트
- 배경: Light Cream
- 각 항목: Pure White 카드, radius 16dp, 수직 간격 8dp, 좌우 패딩 16dp

| 항목 | 타입 | 설명 |
|------|------|------|
| 이미지 품질 | 선택 (높음/보통/낮음) | Soft Coral 칩으로 선택 표시 |
| 자동 저장 | 토글 스위치 | ON: Peach Pink / OFF: Warm Gray |
| 기본 카메라 | 선택 (전면/후면) | Soft Coral 칩으로 선택 표시 |

### 구분선
- 항목 그룹 사이에 얇은 구분선 (Warm Cream, 1dp)

### 앱 정보 섹션
- **앱 버전:** "v1.0.0" (14sp, Warm Gray)
- **라이선스:** 탭 시 라이선스 목록 화면
- **피드백 보내기:** 탭 시 이메일 앱 연동 (Peach Pink 아이콘)

### 하단
- 앱 로고 (작게, 40dp) + "Made with love" 텍스트 (12sp, Warm Gray)
- 강아지 발바닥 아이콘 장식
